# Ramifica Ai

Mapas mentais que crescem com as suas ideias.

## Baixar

Baixe o instalador mais recente em **[Releases](https://github.com/inforprimetecnologiadev/ramifica-ai/releases/latest)** (arquivo `Ramifica-Ai-Setup-<versão>.exe`) e dê dois cliques para instalar.

- Windows 10 ou 11, 64 bits.
- Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.
- Depois de instalado, o app se atualiza sozinho quando sai uma versão nova.

## Recursos

- Mapa mental, gráfico lógico, organograma, árvore e linha do tempo
- Login com Google e sincronização dos mapas entre dispositivos
- Ditado por voz (Ctrl+G), com transcrição feita no próprio computador
- Tarefas com prazos, ícones, notas, links, relações e formas geométricas
- Modo apresentação com slides
- Exportação para PDF, Word, imagem, Markdown, OPML e FreeMind
